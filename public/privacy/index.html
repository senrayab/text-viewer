개인정보처리방침

Text Viewer(텍스트 뷰어)(이하 “서비스”)는 이용자의 개인정보를 중요하게 생각하며, 관련 법령을 지키기 위해 노력합니다. 이 방침은 서비스를 쓰는 과정에서 처리되는 정보의 종류와 목적, 저장 방식, 그리고 이용자의 권리를 안내합니다.

1. 처리 목적 및 수집 항목

서비스는 회원가입이나 로그인을 요구하지 않으며, 이름·이메일 주소·전화번호·주소 같은 개인정보를 직접 수집하지 않습니다. 다만 서비스를 제공하는 과정에서 아래 정보가 처리될 수 있습니다.

  • 접속 정보 — 서비스 파일을 내려 주는 호스팅 사업자(GitHub)와 글꼴 제공자(Google Fonts, jsDelivr)가 운영과 보안을 위해 IP 주소, 브라우저 정보 등을 처리하거나 잠시 보관할 수 있습니다.
  • 이용자가 연 파일과 서재에 담은 데이터 — 이용자가 고른 텍스트 파일의 내용과 이름, 서재에 담은 작품 이름·편 정보·편 내용·표지 이미지는 이용자 브라우저 안의 저장공간에만 저장됩니다.
  • 읽기 기록과 화면 설정 — 파일별로 마지막으로 읽던 위치와 진행률, 테마·글꼴·글자 크기 같은 보기 설정은 이용자 브라우저 안의 저장공간에 저장됩니다.
  • 선택한 외부 서비스 이용 정보 — 구글 드라이브 백업·불러오기를 쓰면 구글 계정 인증과, 승인한 범위 안에서의 드라이브 파일 접근이 일어납니다.

서비스는 광고나 Google Analytics 같은 방문 분석 도구를 쓰지 않습니다.

2. 데이터의 저장 위치와 방식

데이터 저장 위치
서재에 담은 작품·편 정보와 편 내용, 표지 이미지 이용자 브라우저의 IndexedDB
최근 문서(원본 파일 연결 정보와 내용 사본), 새로고침해도 보던 문서를 다시 열기 위한 내용 사본 이용자 브라우저의 IndexedDB
보기 설정, 파일별 읽던 위치와 진행률, 편 목록 정렬 순서, 설치 안내 닫힘 여부 이용자 브라우저의 localStorage
마지막으로 보던 화면(새로고침해도 그 자리에 머물기 위한 표시), 약관·방침에서 앱으로 돌아갈 단계 수 이용자 브라우저의 sessionStorage(탭을 닫으면 사라짐)
구글 드라이브 백업 파일 이용자 구글 드라이브의 앱 전용 공간
구글 드라이브를 연결한 계정의 이메일 주소(다음에 계정을 다시 묻지 않기 위한 표시) 이용자 브라우저의 localStorage
구글 드라이브 접근 토큰 앱을 쓰는 동안 기기의 메모리(따로 저장하지 않음)

텍스트 파일을 열거나 서재에 담는 일, 인코딩 판별, 표지 이미지 크기 줄이기와 대표 색 찾기는 모두 이용자의 기기 안에서 이루어지며, 파일 내용이 운영자의 서버로 전송되지 않습니다. 서비스에는 이용자 데이터를 받는 운영자 서버가 없습니다.

브라우저 저장공간은 브라우저와 사이트 주소마다 따로 있어서, 다른 브라우저나 기기와 자동으로 동기화되지 않습니다. 아이폰에서는 Safari와 홈 화면에 추가한 앱의 저장공간도 서로 따로 있습니다.

3. 외부 네트워크와 서비스 이용

3-1. 서비스 호스팅

서비스 화면과 기능 파일은 GitHub, Inc.의 GitHub Pages로 제공됩니다. 접속하면 파일을 내려받기 위해 GitHub 서버와 통신하고, 이때 GitHub이 IP 주소, 브라우저 정보 등을 처리할 수 있습니다. 구체적인 처리 방식과 보관 기간은 GitHub의 정책을 따릅니다. 서비스는 새 버전이 나왔는지 확인하기 위해 같은 주소의 버전 정보 파일을 가끔 다시 읽지만, 이 접속 정보를 따로 모아 이용자 행동을 분석하지 않습니다. GitHub 개인정보처리방침

3-2. 글꼴

화면을 열 때 글꼴 파일을 아래 제공자에게서 내려받습니다. 이 과정에서 각 제공자가 이용자의 IP 주소 등 접속 정보를 알 수 있으며, 한 번 받은 글꼴은 브라우저에 저장돼 다시 요청하지 않을 수 있습니다.

  • Google Fonts(fonts.googleapis.com, fonts.gstatic.com) — 명조·고정폭 글꼴
  • jsDelivr(cdn.jsdelivr.net) — Pretendard 글꼴과 Tossface 이모지 글꼴

3-3. 파일 열기와 원본 다시 열기

이용자가 파일 선택 창에서 고르거나 화면에 끌어다 놓은 파일만 읽습니다. PC의 Chrome·Edge처럼 지원하는 브라우저에서는 “최근 문서 열기”로 원본을 다시 읽을 수 있도록 파일 연결 정보를 브라우저에 저장하며, 다시 열 때 브라우저가 접근 허용 여부를 묻습니다. 이 연결 정보로는 이용자가 고른 그 파일에만 접근할 수 있습니다. 설정에서 “최근 문서 기억”을 끄면 저장해 둔 최근 문서 정보는 지워집니다.

3-4. 표지 이미지

서재 작품에 표지를 등록할 때 이용자가 고른 이미지를 기기 안에서 작은 크기의 WebP(지원하지 않는 브라우저에서는 JPEG) 이미지로 바꿔 저장하며, 원본 이미지는 보관하지 않습니다. 이전에 크게 저장된 표지도 서재를 열 때 같은 방식으로 줄여 둡니다. 사진에 담긴 촬영 위치 등 부가 정보(EXIF)는 이 변환 과정에서 남지 않습니다. 이미지가 운영자의 서버로 전송되지 않습니다.

3-5. 구글 드라이브 백업과 불러오기

이용자가 이 기능을 열고 구글 계정 접근을 승인했을 때만 쓰입니다.

  • 백업 — 서재 전체(작품 이름, 편 정보, 편 내용, 표지 이미지, 서재에 담긴 편의 읽던 위치)를 압축한 백업 파일 하나를 이용자 본인 구글 드라이브의 앱 전용 공간에 저장합니다. 다시 백업하면 같은 파일을 덮어씁니다.
  • 불러오기 — 백업 파일의 저장 시각과 크기를 읽어 보여 주고, 이용자가 불러오기를 고르면 그 파일을 내려받아 기기에서 서재를 백업 내용으로 바꿉니다.
  • 접근 권한 — 앱이 받는 권한은 drive.appdata 하나입니다. 이 권한은 이 앱만 쓰는 숨겨진 공간에만 닿으며, 이용자 드라이브의 다른 파일과 폴더는 보거나 바꿀 수 없습니다. 이 공간의 파일은 드라이브 목록에 보이지 않습니다.
  • 데이터 저장 — 백업 파일은 이용자의 기기와 구글 드라이브 사이에서만 오갑니다. 운영자는 백업 파일을 서버에 저장하거나 열람하지 않습니다.
  • 인증 정보 — 구글이 발급한 접근 토큰은 기기의 메모리에서만 잠시 쓰이고, 브라우저 저장공간이나 운영자 서버에 저장하지 않습니다. 그래서 앱을 닫거나 새로고침하면 연결이 풀리고, 다음에 쓸 때 구글에 토큰을 새로 요청합니다. 한 번 연결한 뒤에는 계정을 다시 묻지 않도록 연결한 계정의 이메일 주소만 이용자 브라우저에 저장해 두며, 이 요청은 같은 계정으로 조용히 처리됩니다.
  • 삭제 — 백업 화면의 “드라이브 백업 삭제”로 드라이브에 있는 백업 파일을 지울 수 있습니다. 이 기기의 서재는 지워지지 않습니다.
  • 연결 해제와 권한 철회 — 백업 화면의 “연결 해제”를 누르면 저장해 둔 계정 정보를 지우고 구글에 준 접근 권한도 거둡니다. 구글 계정의 타사 앱 연결 설정에서도 언제든 철회할 수 있습니다.

구글 계정 인증과 드라이브 이용 과정의 정보 처리에는 Google 개인정보처리방침이 적용됩니다. 백업 화면을 열지 않으면 구글 로그인 스크립트를 불러오지 않으며(이전에 연결한 적이 있으면 보기 설정을 열 때 미리 불러옵니다), 계정 인증과 파일 접근이 일어나지 않습니다.

4. 제3자 제공

서비스는 이용자의 개인정보를 따로 수집해 제3자에게 판매하거나 제공하지 않습니다. 다만 서비스를 제공하는 과정에서 아래 외부 서비스가 쓰일 수 있으며, 그 정보 처리에는 각 서비스의 방침이 적용됩니다.

  • GitHub, Inc. — 서비스 파일 호스팅과 제공 과정의 접속 정보 처리
  • Google LLC — 글꼴 제공, 구글 드라이브 백업·불러오기를 고르고 승인한 경우의 계정 인증과 파일 처리
  • jsDelivr — 글꼴 파일 제공 과정의 접속 정보 처리

5. 처리의 위탁과 국외 이전

서비스는 이용자의 파일과 서재 데이터를 운영자의 서버에 저장하거나 관리하기 위해 외부 업체에 위탁하지 않습니다.

다만 GitHub Pages 호스팅, 글꼴 제공, 구글 드라이브 같은 외부 서비스를 쓰는 과정에서는 각 사업자가 자기 서비스 제공을 위해 정보를 처리할 수 있습니다. 처리 항목, 보관 기간, 처리 장소와 국외 이전 여부는 각 사업자의 정책과 실제 이용 환경에 따라 달라질 수 있으며, 서비스가 확인할 수 없는 사항은 따로 확정해 안내하지 않습니다.

6. 쿠키와 자동 수집 장치

서비스는 쿠키를 만들거나 읽지 않으며, 광고 쿠키나 Google Analytics 같은 방문 분석 도구를 쓰지 않습니다.

보기 설정과 읽던 위치는 localStorage에, 보던 화면은 sessionStorage에, 서재는 IndexedDB에 저장합니다. 모두 브라우저에 데이터를 저장하는 기능으로, 서버로 함께 전송되는 HTTP 쿠키와는 다릅니다.

다만 호스팅 환경이나 외부 서비스가 자체적으로 쓰는 쿠키나 접속 기록은 해당 사업자의 정책에 따릅니다. 예를 들어 구글 드라이브 기능에서 열리는 구글 로그인 창에는 구글의 쿠키가 쓰일 수 있습니다.

7. 보유와 삭제

서비스는 이용자의 파일과 서재를 운영자의 서버에 보관하지 않습니다. 이용자는 아래 방법으로 직접 지울 수 있습니다.

  • 서재의 편과 작품 — 작품 화면의 편집에서 편이나 작품을, 내 서재의 편집에서 여러 작품을 한 번에 지웁니다. 휴지통이 따로 없어 바로 지워집니다.
  • 최근 문서 — 보기 설정에서 “최근 문서 기억”을 끄면 지워집니다.
  • 브라우저 데이터 — 브라우저 설정에서 이 사이트의 저장 데이터를 지우면 서재, 읽기 기록, 설정이 모두 지워집니다.
  • 구글 드라이브 백업 — 앱의 보기 설정 → 구글 드라이브 백업 화면에서 “드라이브 백업 삭제”를 누르거나, 구글 드라이브 웹의 설정 → 앱 관리에서 Text Viewer의 옵션 → “숨겨진 앱 데이터 삭제”로 지울 수 있습니다.

브라우저 데이터 삭제, 브라우저·기기 변경, 기기 초기화, 저장공간 정리 등으로 지워진 데이터는 복구할 수 없을 수 있으니, 중요한 서재는 미리 백업해 두세요. 이용자의 원본 텍스트 파일은 서비스가 바꾸거나 지우지 않습니다. 앱의 구글 드라이브 접근 권한을 철회해도 이미 저장된 백업 파일은 자동으로 지워지지 않습니다.

8. 아동의 개인정보

서비스는 이용자의 나이를 확인하지 않으며, 아동의 개인정보를 따로 수집하지 않습니다. 구글 드라이브 백업·불러오기를 쓰는 경우에는 구글 계정 이용에 관한 구글의 정책과 관련 법령이 적용됩니다.

9. 이용자의 권리와 책임

이용자는 서비스에 저장된 데이터를 직접 확인·수정·삭제하고 백업할 수 있습니다. 운영자는 이용자의 브라우저에 저장된 데이터에 접근할 수 없으므로, 그 데이터의 열람·수정·삭제·복구를 대신할 수 없습니다. 개인정보 처리에 관한 문의는 아래 문의처로 보내 주세요.
